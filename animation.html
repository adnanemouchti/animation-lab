C.4 — CRÉER DES ANIMATIONS

CSS Animation Lab

Découvrez comment utiliser CSS pour créer des transitions, des transformations et des animations.

01

Transition

CODE CSS 
.transition-button {
    background: #315efb;
    transition: 0.5s;
}

.transition-button:hover {
    background: #9b51e0;
    transform: scale(1.1);
}
RÉSULTAT

Comment ça fonctionne ?

La propriété transition permet de rendre un changement progressif. Lorsque l'utilisateur passe la souris sur le bouton, sa couleur change et sa taille augmente progressivement pendant 0,5 seconde.

02

Transformation

CODE CSS 
.transform-box {
    transition: 0.5s;
}

.transform-box:hover {
    transform:
        rotate(15deg)
        scale(1.2);
}
RÉSULTAT
CSS

Comment ça fonctionne ?

La propriété transform permet de modifier l'apparence ou la position d'un élément. Ici, nous utilisons rotate() pour faire tourner l'élément et scale() pour l'agrandir. La transition rend ces changements progressifs.

03

Loading Line

CODE CSS 
.loading-ball {
    animation:
        loading 3s
        infinite
        linear;
}

@keyframes loading {

    0% {
        left: 8%;
    }

    70% {
        left: 88%;
    }

    100% {
        left: 8%;
    }
}
RÉSULTAT

Comment ça fonctionne ?

Cette animation utilise des keyframes pour déplacer une balle sur une ligne horizontale. La balle avance progressivement vers la droite jusqu'à 70% de l'animation, puis revient plus rapidement vers sa position initiale. L'animation se répète continuellement.

04

Balle en Zig-Zag

CODE CSS 
@keyframes zigzag {

    0% {
        left: 3%;
        top: 10%;
    }

    20% {
        left: 90%;
        top: 10%;
    }

    40% {
        left: 15%;
        top: 35%;
    }

    60% {
        left: 85%;
        top: 55%;
    }

    80% {
        left: 10%;
        top: 85%;
    }

    100% {
        left: 90%;
        top: 85%;
    }
}
RÉSULTAT

Comment ça fonctionne ?

Les keyframes permettent de définir plusieurs positions pour la balle. Chaque pourcentage représente une étape de l'animation. La balle se déplace ainsi dans différentes directions et traverse toute la zone de démonstration en formant un mouvement en zig-zag.

05

Élément Flottant

CODE CSS 
.floating {
    animation:
        floating 2s
        infinite
        ease-in-out;
}

@keyframes floating {

    0% {
        transform: translateY(0);
    }

    50% {
        transform: translateY(-25px);
    }

    100% {
        transform: translateY(0);
    }
}
RÉSULTAT
✦

Comment ça fonctionne ?

Les keyframes définissent trois étapes : la position initiale à 0%, la position supérieure à 50% et le retour à la position initiale à 100%. L'animation se répète continuellement grâce à la valeur infinite.
